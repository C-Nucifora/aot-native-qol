# Open release gaps

1. Project license and original-source authorship/provenance need confirmation.
   No LICENSE is invented or inherited from unrelated software.
2. Original game font/glyph-derived menu textures, layouts and generated guard
   bytes cannot be included in this source package. Seven-value extraction and
   generation are now locally reproducible through the documented workflow.
   Resolution-label donor/extraction and packing are now locally reproducible
   through local-resolution-assets.md. Both sidecar pairs remain private outputs.
3. The supported original-layout image contract and actual preparation provenance
   are documented in unpacked-image-prerequisite.md, but a fresh-install image
   preparation command is not provided. No image or unpacking tool is bundled.
4. The identified core game signatures and displaced replay bytes are now
   generated privately. The private migration and package reviews accepted this source-only form. Mod-authored instruction emitters
   remain source, including the camera relay's new XMM15-to-XMM2 argument copy.
5. Six existing synthetic portable host checks are included. Full native/image
   integration checks still need portability work and remain private.
6. The reported nape stall passed a user-played replay on 12 November 2026. No broad claim of unchanged
   gameplay across all high-FPS content is made.
7. AA and HD UI are deliberately excluded. If added later, retain their exact
   SMAA/CAS upstream notices and provenance, document shader-tool licensing and
   locally generate outputs. Their reviews do not license game-derived UI art.

This is source preparation, not a distribution-rights determination.
